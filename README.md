# Road-Accident-Data-Analysis-Excel-Dashboard

## 📌 Project Overview
This project provides a comprehensive analysis of road accident data to identify key trends and factors contributing to road incidents. [cite_start]Using **Microsoft Excel**, I developed an interactive dashboard to transform complex datasets into actionable insights, aimed at supporting data-driven decisions for public safety and road improvement. [cite: 3, 4, 42]

## 🚀 Key Features
* [cite_start]**Interactive Dashboard**: Designed a user-friendly interface to convert raw data into meaningful visual stories. [cite: 4, 41]
* [cite_start]**Dynamic Data Summarization**: Leveraged Pivot Tables and Charts to provide high-level and granular views of accident metrics. [cite: 19, 20]
* [cite_start]**Advanced Filtering**: Integrated multi-functional Slicers to allow users to drill down by region, time, and road conditions. [cite: 21]
* [cite_start]**KPI Monitoring**: Real-time tracking of critical metrics such as casualty severity and vehicle involvement. [cite: 25, 26]

* [cite_start]**Temporal**: Accident Date, Day vs. Night analysis. [cite: 9, 15]
* [cite_start]**Environmental**: Road Type, Road Surface Conditions, and Location (Urban/Rural). [cite: 12, 13, 14]

## 📈 Key Performance Indicators (KPIs)
[cite_start]The dashboard tracks 417,883 total casualties with the following distribution: [cite: 27, 45]
* [cite_start]**Fatal Casualties**: 7,135 (1.7%) [cite: 28, 48, 51]
* [cite_start]**Serious Casualties**: 59,312 (14.2%) [cite: 28, 49, 52]
* [cite_start]**Slight Casualties**: 351,436 (84.1%) [cite: 29, 53, 54]
* [cite_start]**Casualties by Car**: 333,485 (79.8%) [cite: 30, 55, 56]

---

## 🔍 Key Insights
1. [cite_start]**Severity Trend**: Slight casualties constitute the vast majority (84.1%) of total cases. [cite: 34, 54]
2. [cite_start]**Vehicle Risk**: Cars are the primary vehicle type involved in accidents, accounting for nearly 80% of casualties. [cite: 35, 56]
3. [cite_start]**Infrastructure Impact**: Single carriageway roads are identified as high-risk infrastructure points. [cite: 36]
4. [cite_start]**Geography & Lighting**: Accidents are more frequent in **Urban areas** and during **Daylight** hours. [cite: 37, 38]
